# Backend — FastExpress

API REST del módulo de cotización de envíos y descuentos (Google Apps Script, web app).
**Responsable:** Backend.

## Contenido esperado
- `src/` — código de la API y de la función core de cálculo (BR-01 a BR-04).
- `tests/unitarias/` — pruebas unitarias de la función de cálculo.
- `tests/api/` — pruebas de endpoints y del contrato.
- `package.json` — configuración de la suite (Jest o equivalente) y script de cobertura.

## Pendiente de completar por Backend
- Cómo desplegar la web app y dónde queda la URL (el Frontend la lee de `VITE_API_URL`).
- Cómo correr las pruebas y la cobertura (`npm test`, `npm run coverage`).
